# User Management Application

## Project Overview
A user management application developed using React and Vite. It allows users to view user details fetched from an API, add new users, edit existing users, 
and delete users.

## Technologies Used
- React.js
- JavaScript
- Vite
- JSONPlaceholder API

## React Concepts Practiced
- Functional components
- Props and component communication
- useState for state management
- useEffect for API data fetching
- Form handling and validation
- Conditional rendering
- map() for displaying users
- Spread operator
- Event handling

## Features
- Fetch and display users from an API
- Add users with name and email
- Validate form inputs
- Edit existing user details
- Delete users
- Display a loading message while fetching data

## API Used
https://jsonplaceholder.typicode.com/users

## How to Run
1. Clone this repository.
2. Open the project folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL displayed in the terminal.
